Manual transfer safety

  • For deposits, use the exact network and address shown by your receiving wallet.
  • TRC20 USDT requires the TRON network and may require TRX for wallet network fees later.
  • Verify destination address and network independently before sending; blockchain transfers are generally irreversible.
  • MuB never requests Binance API keys, a seed phrase, or private key on this page.
  • Never count simulated paper profits as real funds.
